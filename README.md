# Noir · Blade Ball

Скрипт для Blade Ball: авто-парирование, авто-спам и ручной спам парирования.

## Возможности

**Auto Parry**
- предсказание точки встречи мяча и персонажа с учётом пинга;
- срабатывание только когда мяч летит именно в вас;
- отдельная обработка кривых мячей (уменьшенная зона срабатывания);
- не тратит парирование, пока блок на кулдауне;
- два способа ввода: имитация нажатия (Keypress) или прямой вызов remote (Remote).

**Auto Spam**
- спам парирования с настраиваемой частотой 5–60 раз в секунду;
- режим «Clash spam» — спам даже когда мяч летит не в вас;
- опция «Respect cooldown» — не спамить при кулдауне блока.

**Manual Spam**
- ручной спам по клавише (по умолчанию X), hold или toggle;
- опция «Only with ball» — не спамить в пустоту;
- отдельная круглая кнопка SPAM для мобильных устройств.

**Интерфейс**
- перетаскиваемая панель в стиле Noir;
- живые счётчики парирований и спамов;
- статус, пинг, скорость мяча и дистанция до него;
- сохранение настроек между запусками.

## Установка

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/<ваш-логин>/<репозиторий>/main/Noir_BladeBall.lua"))()
```

Либо вставить содержимое файла в исполнитель напрямую.

## Поддерживаемые исполнители

Delta, Arceus X, Codex, Xeno и другие, поддерживающие `loadstring`/`HttpGet`.

## Настройка

| Ситуация | Рекомендация |
|---|---|
| парирует слишком рано | Distance scale 0.85 |
| пропускает мячи | Distance scale 1.15–1.3, Ping compensation — ON |
| не ловит кривые | Curve guard — ON, Distance scale 1.2 |
| проигрывает клэши | Auto Spam + Clash spam — ON, Rate 30–40 |
| нужен максимально скрытный режим | Mode: Keypress, Respect cooldown — ON, Rate 10–15 |
